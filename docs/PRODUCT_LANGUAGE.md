# Storymaker product-language standard

## Visual directions, not imitation modes

Storymaker helps a director describe visual intent. Public presets are made from transferable traits: medium, materials, proportion, palette, texture, camera language, lighting, pacing, and audience.

The interface does not sell named imitation modes for living studios, artists, or franchises. A director can still use familiar cultural references in a private working prompt, but Storymaker translates that input into editable traits before it becomes the production direction.

Examples:

| Conversational intent | Public Storymaker direction |
| --- | --- |
| warm, rounded family-animation feeling | Character-Forward 3D · rounded forms · expressive faces · warm global illumination |
| hand-painted Japanese storybook feeling | Hand-Painted Whimsy · watercolor texture · pastoral color · gentle motion |
| painterly prestige fantasy animation | Painterly Feature Animation · brush texture · sculpted light · cinematic staging |

## Render-look profiles are not renderer integrations

The early product may offer broad look controls such as **Cinematic Photoreal**, **Dramatic Global Illumination**, **Product Ray-Light**, and **High-Contrast CGI**. These are prompt and art-direction profiles only.

They are not V-Ray, Redshift, Arnold, or any other renderer integration. Native 3D pipeline support belongs to a future professional workflow with declared scene interchange, renderer availability, licensing, GPU configuration, and render-job reporting.

## Mode promise

**Simple Mode** is a guided, low-friction path: story → characters → storyboard → generate → voice/edit → deliver. It hides optional complexity and defaults to an opinionated production recipe.

**Studio Mode** keeps the same connected project record but reveals selective regeneration, performance notes, cinematography, continuity signals, reference roles, per-shot model controls, and delivery review. It is depth on demand, not a separate product.
