# Storymaker visual-preset artwork

Storymaker uses a deliberately small set of rich **collection boards** rather than demanding a bespoke image for every visual direction. A single board can support closely related directions; the direction's own name, tone, prompt recipe, model controls, and continuity rules still remain distinct.

This makes the Design Bible feel complete today without pretending that every variation needs its own illustration.

## Replacing a shared board later

1. Export a full-frame landscape image (16:9, 2560 x 1440 or larger is ideal).
2. Place it in `assets/styles/` with the exact preset filename, such as `Film Noir.png`.
3. Rebuild Storymaker.

Direct preset artwork takes priority over the shared collection anchor. The Design Bible does not show administrative **ART PENDING** or **ART READY** labels: every direction is selectable and presented as a production-ready visual language.
