# 0.4.45 — Production asset continuity

- Adds **Accessory** as a first-class production-asset type alongside props, wardrobe, vehicles, creatures, weapons, and products.
- Scene assignments now carry every selected reference for a set or production asset, not merely its primary image. Material, angle, and context references therefore reach compatible image and video generation.
- The Media Library now reports references used by Locations and Props, making it safer to review or remove assets.
