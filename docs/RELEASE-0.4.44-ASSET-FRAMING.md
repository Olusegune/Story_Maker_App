# Story Maker 0.4.44 — Whole-asset review

- Character Turnaround tiles now fit the entire image instead of cropping the head or silhouette.
- Shared reference-library hero and thumbnail framing also uses fit-to-view behavior.
- Because the Character, Set, and Prop Labs share that component, the correction applies consistently across all three asset systems.
# Windows package

The 0.4.44 release was validated with the application syntax checks, visual-direction smoke checks, release smoke checks (220 checks), the production web build, and a Windows Electron package build. The release folder includes both an installer and a portable Windows executable in `dist-release`.
